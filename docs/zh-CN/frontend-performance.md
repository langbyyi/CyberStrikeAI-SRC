# 公网前端加载优化

2026-10-12，针对公网部署站点的前端加载优化。

## 实测结果

同一浏览器、同一公网地址，无缓存刷新；统计导航及资源传输量，包含语言包。

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 两次无缓存页面加载 | 25.06 / 24.94 秒 | 4.03 / 3.93 秒 |
| 首屏传输 | 9,260,274 字节 | 1,520,349 字节 |
| 已缓存后的普通刷新 | 未测 | 0.64 秒 |
| 首屏 ELK / SheetJS 请求 | 2 个 | 0 个 |

修复图布局的加载状态与异常处理后，最终公网复测：无缓存加载 4.62 秒、首屏 1,520,403 字节，缓存刷新 0.52 秒；无失败请求和控制台错误。

首次加载耗时减少约 84%，传输量减少约 84%。公网测量覆盖登录页及前端初始化；登录后的功能使用隔离账号和合成数据验证，未对线上私人数据操作或调用外部模型与扫描服务。

## 实现

- Go 服务直接压缩 `/`、`/api-docs` 的 HTML，以及可压缩的静态文本文件；8080 直连即可生效，不依赖反向代理。
- 静态文件的 gzip 结果缓存在内存中，文件大小或修改时间变化时重新生成。缓存限制为 128 项，单个源文件最多 8 MiB。
- 静态文件使用 `Cache-Control: public, max-age=0, must-revalidate`，gzip 版本提供 ETag，支持 304。现有资源版本参数并非内容哈希，因此不使用永久缓存。
- HEAD、Range、不能接受 gzip 的客户端保持正常 HTTP 语义。压缩范围不包含鉴权 API、SSE、WebSocket。
- ELK 和 SheetJS 仅在图布局或表格导入导出时加载；并发调用共享加载请求，失败可重试。变更的调用脚本更新了版本参数，避免已有浏览器继续使用旧逻辑。
- 切换或关闭攻击链弹窗会作废等待中的渲染，项目事实图亦检查实例是否仍有效。

## 验证

- `go test ./... -count=1`：Windows 与 Linux 全套通过。
- `go test -race ./internal/app -run 'TestFrontend' -count=1`：Linux 通过。
- `go build ./cmd/server`：Windows 通过；服务器以 `go build -o cyberstrike-ai ./cmd/server` 构建通过。
- `node --test web/tests/*.test.cjs`：335 项通过。
- 浏览器实测按需加载后，真实 SheetJS 写入/读取工作簿和 ELK 节点布局均成功；控制台无错误或警告。
- 线上验证 gzip 200、空响应体 304 和服务 active。
- 隔离环境中实际登录、23 个非 C2 页面导航、表格模板生成、XLSX 导入持久化、CSV/XLSX 资产导出、信息收集结果表格导出及攻击链渲染通过。C2 在该隔离环境中主动关闭，未启动监听器或外部会话。
- 实际浏览器确认首次图布局依赖加载期间保留加载提示；异步渲染失败进入原有错误显示，切换/关闭弹窗会丢弃过期渲染。窄屏页面未出现整个页面的横向溢出。

## 部署与回退

部署前为原二进制及本次修改文件建立独立备份，保留原运行目录内其他改动。回退时恢复这些文件、移除本次新增文件并重启服务。正常运行仍由原 systemd 服务和 `run.sh` 管理。

仓库仅保留合成测试数据与汇总测量结果，不记录实际部署地址、私人目录、凭据、截图、运行日志或数据库。
