# 移动端兼容性核查

核查日期：2026-10-13。

## 官方版本与二开差异

- [官方 v1.7.22](https://github.com/Ed1s0nZ/CyberStrikeAI/releases/tag/v1.7.22) 引入移动端导航、抽屉、手势、聊天和弹窗布局、软键盘及安全区域适配。
- [官方 v1.7.23](https://github.com/Ed1s0nZ/CyberStrikeAI/releases/tag/v1.7.23) 主要新增漏洞复测。
- 修复前，本地 `mobile.css`、`mobile-ui.js`、`api-docs-mobile.css` 和 manifest 与 v1.7.23 一致；核查重点是二开接口、词典和运行时视口兼容性。

## 修复内容

1. 移动端待审批角标改用携带登录令牌的 `apiFetch` 和现有统一审批接口，读取服务端总数。工作流节点等待仍来自独立接口，按两种读取权限分别计数。
2. 登录后立即刷新角标，退出时清空并丢弃迟到响应，隐藏页面不发起周期请求。
3. 视口宽度变化时重置高度基准，仅在可编辑控件聚焦且视口缩小时判断软键盘；避免横屏、缩放和失焦后错误隐藏底栏。
4. 恢复中英文 `chat.rolePanelTitle` 译文，修复俄语切回中英文后角色面板标题保留俄语的问题。
5. 触控审计接受 0.5 CSS 像素的舍入误差，识别可点击标签及伪元素扩展的真实命中区；移除不存在的路由，并校验每次跳转实际激活的页面。

## 验证

- `node --test web/tests/*.test.cjs`：342 项通过，包括新增的角标鉴权、工作流计数、权限、登录/退出、横屏和失焦回归。
- `node --check web/static/js/mobile-ui.js` 与 `node --check scripts/mobile-tap-audit.mjs`：通过。
- 隔离实例使用临时数据库和合成数据。320×568、390×844 的 23 个可用页面逐页检查：路由激活正确，无页面横向溢出，修正后的触控审计未发现不可达或过小的目标。
- 667×375 横屏聊天页底栏可见；768×1024 的主要页面无横向溢出；1280×800 桌面端不显示移动外壳。
- 验证菜单抽屉及关闭操作、更多面板、角色面板、审批内容、项目弹窗和 API 文档布局；中英俄导航和角色标题切换正常。
- 将资产全选的透明命中区域临时缩小到 30px 时审计失败，恢复 44px 后通过，证明判据没有掩盖小目标。

## 验证边界

浏览器验证使用 Chromium 的手机视口、触摸模式和 iPhone/Android UA，并非真实 iOS Safari 或 Android 设备。软键盘逻辑由回归测试验证，真实输入法和浏览器工具栏还需设备验收。隔离实例关闭 C2 与外部模型，未执行外部扫描或审批决定；未覆盖 C2 实际业务、系统文件选择器或设备手势。

本次改动不增加依赖，不修改数据库结构。临时配置、密码、数据库、日志和测试产物位于 Git 忽略的目录，不作为提交内容。
